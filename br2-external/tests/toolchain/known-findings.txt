# The findings of tools/isa-gate in the toolchain's own libraries, as the
# toolchain job expects them. The gate is run over every target object of the
# toolchain that configs/toolchain_defconfig builds (br2-external/README.rst,
# "The instruction-set gate over the toolchain's own objects"), and
# compare-findings holds what it reports to this list: the job passes when the
# findings are exactly these, and fails when one is new, gone or different.
#
# The two functions are in the libraries of libgcc and of uClibc-ng and are
# built for every MIPS target; a third, uClibc-ng's __cxa_finalize, left the
# list with the carried patch of the exit handlers (buildroot/README.rst). A
# program that links the C library statically takes only the objects it refers
# to, so neither is in a static program; the image's programs share a C library
# cut to what they import, which leaves out _test_and_set, and the image does
# not ship libgcc_s (docs/adr/0011).
#
# One line for each file, archive member and function: the number of findings,
# the file (below the toolchain directory), the archive member (- for a file that
# is not an archive), the function, and the instructions in the order the gate
# reports them: the mnemonic of each, and for a word that a listing as MIPS I
# leaves as data, the word (.word=0xf is sync; .word=0x3e00408 is jr.hb). When
# the toolchain changes on purpose, "compare-findings --print-known" writes the
# new list from the gate's output.
#
